# AniLearn

AI 一对一学习平台，提供试卷学习、英语／日语外刊导读、逐章典籍导读和无需材料的自由提问，使用 Next.js、Drizzle 和 PostgreSQL。

## 本机启动（Windows / Docker Desktop）

### TUI 启动器

双击项目根目录的 `AniLearn.cmd`，或在 Windows Terminal 中运行 `npm run launcher`。需要 Node.js 22 或更新版本及已安装的 Docker Desktop；缺少 npm 依赖时会自动安装。启动器自动开启 Docker 的 Linux 引擎、本项目 PostgreSQL 和 AniLearn，默认使用生产模式，保留上次选择的模式与端口。网页就绪后按 `O` 打开。

面板显示应用、数据库与 Docker 状态、按来源筛选的实时日志、CPU/内存曲线、数据库容器收发流量，以及只读的数据库大小、连接数和业务数量统计。不会读取消息正文、试卷内容或 API 密钥。终端变窄后按 `Tab` 切换日志、资源和统计；大窗口同时显示全部面板。

| 按键 | 操作 |
| --- | --- |
| `S` / `X` / `R` | 启动全部 / 停止全部 / 重启应用 |
| `M` / `B` / `O` | 切换生产开发模式 / 重新构建并启动 / 打开网页 |
| `Q` / `Ctrl+C` | 关闭应用和本项目 PostgreSQL 后退出，保留数据卷 |
| `D` | 确认后保留后台服务并退出；再次打开可重新连接 |
| `H` | 操作菜单，方向键选择、回车执行 |
| `1`–`4` / `/` / `E` | 日志来源 / 搜索 / 仅错误 |
| 空格 / 方向键 / `End` | 暂停跟随 / 滚动日志 / 回到底部 |
| `C` / `V` / `N` | CPU / 内存 / 数据库容器流量曲线 |
| `Tab` 然后方向键 | 切到统计面板并滚动，查看全部统计与进程 |

```powershell
npm run launcher -- --port 3001 --mode development
npm run launcher -- --no-autostart
```

生产构建按源文件、资源、配置和构建 ID 检查，未变化时复用；首次启动或输入变化时重新构建。启动器的开发模式使用 Next 的 Webpack 选项，以规避 Windows 强制结束后 Turbopack 持久缓存造成的路由异常。缺少 `.env.local` 或数据库表结构会显示修复提示，启动器不会自动同步或重置数据库。关闭时只处理已核验的 AniLearn 进程树及本项目 Compose 数据库，不关闭 Docker Desktop。终端意外退出后，后台管理器在连接丢失约 15 秒后执行同样的清理；电脑强制关机无法保证及时执行清理。

运行状态、偏好、构建指纹及脱敏轮转日志位于被 Git 忽略的 `.anilearn/` 中。数据库日志仅保留生命周期信息和异常标记，过滤 SQL、参数和业务错误详情。外部手动启动的同项目服务可识别并停止，但无法接管其历史标准输出。以下手动启动方式仍然可用。

### 手动启动

1. 启动 Docker Desktop，使用 Linux 容器。
2. 安装依赖：`npm install`。
3. 首次配置时，复制环境变量模板：

   ```powershell
   Copy-Item .env.example .env.local
   ```

   将 `.env.local` 中的 `POSTGRES_PASSWORD` 替换为随机十六进制密码。`DATABASE_URL` 会自动使用同一文件中的用户名、密码、端口和数据库名。已经配置好的 `.env.local` 无需重新复制。

4. 启动数据库并等待就绪，然后创建本地数据库表：

   ```powershell
   npm run db:up
   npm run db:push
   ```

5. 启动开发服务：

   ```powershell
   npm run dev
   ```

   打开 http://localhost:3000。首次访问会自动创建预设导师。模型和 Fish Audio API 密钥在「设置」中填写。

默认导师为《少女与战车》中的大吉岭，Fish Audio 声音 ID 为 `db1553e441c84b49bf250912563ec8fc`，语音使用日语。旧版预设艾琳会更新为大吉岭并保留原导师 ID，已有课堂仍能关联到她。其他导师可在「我的导师」中编辑。

若服务器无法直连 Fish Audio，可在「设置」的语音区域填写 HTTP/HTTPS 代理地址，例如 `http://127.0.0.1:18081`。代理只用于 Fish 语音合成与声音搜索，保存后立即生效；Windows 系统代理不会自动应用到服务器请求。代理地址留空保留现有配置，点击旁边的「清除」恢复直连。地址可包含代理用户名和密码，页面仅返回脱敏预览；无需数据库迁移。「保存并试听」每次重新合成，用于验证最新配置；失败时分别提示连接、密钥、余额和限流等原因。

预设导师也包括《Fate/stay night》中的远坂凛和阿尔托莉雅，以及晴人。所有导师均可指导任意学科，材料决定当前学科。旧版预设凛、小樱分别更新为远坂凛、阿尔托莉雅，保留原导师 ID 和课堂关联。阿尔托莉雅 Fish reference id 为 `4aa42286f3844a29a243e2ebd29f815f`。

## 导学与模型设置

「服务商连接」保存名称、接口类型、地址与密钥；「模型用途」分别绑定讲解和分析模型。支持 OpenAI、Anthropic、xAI、Gemini 和自定义 OpenAI-compatible，同一服务商可保存多个连接，模型名称自由填写。旧配置自动转换，保留密钥与环境变量回退。分析模型负责目录、选讲计划、详细解析和补充解析；讲解模型负责课堂对话、语音台本与消息修复。被引用的连接须重新绑定后才能删除。

新试卷默认「纲举目张」，上传、开课和课中均可调整：条分缕析逐题完整讲解；纲举目张覆盖重点并选代表题去重；由博返约聚焦核心主线；游刃有余聚焦难题、陷阱与错题；羽登化境开展推广与变式，并标明超纲内容。上传与开课可填写学习需求，课中也可向导师明确提出范围调整。

学习计划显示代表题、关联题、具体目标及理由。未选题显示「未纳入本课」，不会记为掌握。扩大范围需要新增解析时，先列出补充题目，点击确认后执行；失败保留原计划与已完成草稿。补充成功后原子应用新计划，重试绑定计划版本和原材料版本。

## 外刊导读

从 `/readings` 上传单篇英语或日语文章，支持不限页数的 PDF、图片、Markdown、纯文本、剪贴板图片和粘贴原文；单个文本来源最多 1.5 MB。通过「从剪贴板添加」或 Ctrl+V／⌘V 导入图片，也可导入公开共享且允许导出的 Google Docs 链接；文档按 PDF 导入全部标签页并保留版式，导出文件最大 20 MB。全部来源上传后自动逐页识别，关闭网页后继续运行；应用重启或识别失败后可从已完成页续接。识别完成后按来源页校对，确认全文后开始阅读。

阅读课堂分为自由阅读和文章分析。自由阅读阶段导师保持静默，学生可通读全文、划词询问词义／语法／句意、写全文笔记并对选区添加批注；提问后导师再用中文解释和日语配音回答。读完整篇后，学生手动开始文章分析。导师结合全文上下文引导讨论结构、写作思路和主旨；识别为文学作品时，还会分析情感和表现手法，学生可手动纠正文章类型。每个角度由学生确认，最后由导师整理总结并由学生确认完成。超过长度阈值的文章按段落分块准备全文依据，失败或应用重启后可续接已保存的工作。

外刊与典籍共用连续阅读器。桌面可调整导师分栏宽度或收起导师，手机通过底部面板讨论；正文支持按屏移动、全文搜索、划选与原处批注。阅读设置可调整字体、字号、行距、正文宽度和纸白／暖纸／深色主题，并保存本地偏好。内部窗口随滚动预加载，不需要手动切换段落组；字体或宽度变化后按文字位置恢复。查看引用或批注时保留返回点，点击继续阅读才将新位置保存为书签。

学生书签、个人笔记、原文批注和导师分析独立保存；刷新或重新进入课堂后可继续原有阶段。历史课堂的聊天和笔记仍可查看，历史逐段完成记录不会自动标记为整篇文章分析完成。

中文解释与带语言标识的外语引用分别显示；配音仍为日语台本。原文引用和外语例句直接显示，不自动合成语音或等待逐字揭示。阅读课堂保留开课原文快照，重新校对材料不会覆盖历史内容。

## 典籍导读

从 `/books` 进入书架，默认包含 `books/Selected Dialogues of Plato.epub`，首次进入自动初始化，不调用模型或配音。五篇对话按 Ion、Protagoras、Phaedrus、Symposium、Apology 组织学习单元，前言、附属内容、插图和跨文件脚注仍可查看。

支持上传 EPUB、MOBI，单文件最多 50 MiB，累计解压最多 256 MiB。EPUB 以正文顺序和 EPUB 2／3 目录共同切章；书内脚本和外部依赖不会执行。MOBI 需要安装 Calibre 并在 `.env.local` 配置 `CALIBRE_EBOOK_CONVERT` 为 `ebook-convert.exe` 的绝对路径，路径中的空格无需额外引号。工具缺失、转换失败、加密或损坏时显示错误；上传 EPUB 不依赖 Calibre。

导入完成后校对目录：重命名、调整层级、按正文块拆章、合并相邻章节，以及标记前言／正文／附录。确认时选择文学、思想论说或文言类型。原文件和解析检查点保留，失败或服务重启后手动续接；已发布目录的校对生成新版本，旧课堂继续使用原版本。

课堂静默进入自由阅读，学生提问后导师才回应。确认读完本章后开启导读，依次讨论作品类型对应的固定角度，逐项确认后生成章总结；跳章和回看不会自动标记完成。所有正文学习单元确认已读后，可主动生成全书总结，不要求每章都完成导读。准备和全书整合保留检查点，失败或重启后手动续接。

个人批注、本章笔记和全书笔记按内容版本共享，各导师课堂的聊天与学习进度独立。模型默认只接收当前问题相关原文、本章已经开启的资料、已确认读完的前章记忆和相关历史；后章资料不会自动附带，全书私人笔记由学生主动选择附带。中文解释、原文引用和日语配音分别处理；上下文边界与引用格式校验不能替代教学准确性的人工核查。

新版需要先审查并应用[典籍与共享阅读器增量迁移](docs/migrations/20261013-books-shared-reader.sql)，或在已备份的目标数据库运行 `npm run db:push`。保留已有阅读器字段和历史记录。`npm run books:test` 检查导入、目录覆盖、章节状态、上下文和锚点；`node output/audit/books-api.mjs` 与 Playwright CLI 脚本用于隔离环境验收。

## 自由提问

从首页导航进入「自由提问」，选择一位导师即可直接开始，不用上传试卷或外刊，也不需要选择学科、年级或学习计划。导师会先欢迎你，再按问题讲解；可以连续追问、切换话题或附上图片。文字与图片按轮次保存，超长对话可以恢复较早消息；图片按需读取。每个话题有独立黑板页，可查看旧页、回到原话题继续，并下载全部板书为 Markdown。课堂名称可编辑，也可删除整段交流。

自由课堂沿用中文聊天和板书、日语语音及原子文字揭示规则。连续讲解默认跟随设置中的 `autoContinue`，每次学生输入最多自动追加六轮；静音时只播放文字揭示，不请求 TTS。结束交流只发送简短告别，不改变试卷课堂进度；返回首页要等告别流结束且语音／文字播放队列清空。

自由模式使用讲解模型连接，不依赖分析模型、OCR 或 Fish Audio 密钥；没有语音配置时仍可使用文字课堂。最多可发送 4 张图片，每张在浏览器压缩至 2 MiB 以内，文字输入上限为 4,000 字。首版不提供文件导入、联网检索、语音输入或跨会话长期记忆。更多接口和恢复约定见[自由提问工程说明](docs/free-mode.md)。

上传中断后可在当前上传页点击「续传未完成来源」，沿用已创建文章并跳过已上传页。识别进度逐页保存；每页识别失败会重试一次，仍失败则停止并显示「续接识别」。旧文章保留全文编辑，重新识别后切换为分页校对。整篇确认不再限制 1.5 MB 或 1000 段，原文分段的页码直接取自来源页。后台处理适用于持续运行的本地 Node.js 服务；应用重启后不会自动重启任务，需要手动续接。

## 图片资源

四位预设导师的头像保存在 `public/avatars/`，首页课堂插画保存在 `public/images/hero.jpg`。这些图片随项目一起部署。

生成模型为 `gpt-image-2.5-sunburst`（接口中的正式名称）。大吉岭的头像和首页插画以 `025_darjeeling.webp` 为人物参考，保留参考图的发型、校服和茶杯特征。完整提示词保存在 `output/imagegen/prompts.json`，原始图片保存在同一目录，网页资源清单保存在 `output/imagegen/assets.json`。网页头像使用压缩后的 512 × 512 PNG，首页插画使用 JPEG。重新生成时，图片接口地址和密钥分别通过 `.env.local` 的 `IMAGE_GENERATION_BASE_URL` 和 `IMAGE_GENERATION_API_KEY` 配置。

阿尔托莉雅头像使用已授权的 imagegen 备用脚本与 `gpt-image-2` 生成，项目内 `scripts/generate-artoria.cjs` 将图像服务结果转换为原脚本接受的 base64 格式，不修改技能脚本。完整提示词保存在该脚本中，网页资源为 `public/avatars/artoria.png`（512 × 512）。脚本读取同一组 `IMAGE_GENERATION_*` 配置，密钥不会打印。

Next.js 在构建收集路由时会加载数据库模块，因此构建环境也必须提供 `DATABASE_URL`。本机使用项目根目录的 `.env.local`；远程构建和部署环境应分别配置指向相应数据库的 `DATABASE_URL`。`drizzle.config.ts` 也读取 Next.js 环境文件，应用和建表工具共享连接配置。

## 试卷解析与课堂恢复

单份试卷最多 12 页。超过限制的 PDF 会提示实际页数，需要拆分后上传，不会只取前几页。上传页也支持 Ctrl+V／⌘V 粘贴图片，以及导入公开共享且允许导出的 Google Docs 链接；Google 文档按 PDF 导入全部标签页，保留可见公式、插图和版式，导出文件最大 20 MB。剪贴板按钮优先读取图片，没有图片时识别 Docs 链接；文字输入框保留正常粘贴。

支持图片、PDF、Markdown（`.md` / `.markdown`）和 LaTeX（`.tex`）试卷，也可混合上传并调整顺序。每个文本文件作为一个来源页，最多 1.5 MB，须使用 UTF-8 编码。原文保存在现有页面表中，无需数据库迁移；分析模型直接读取原文，保留公式与宏定义。Markdown 预览渲染文字与公式，LaTeX 预览显示源码，不编译或执行 TeX。外部图片及 `\input` / `\include` 依赖不会自动读取，应在文本中提供必要内容或另行上传相关图片。

解析先建立完整题目清单并轻量分类，再生成学习计划，仅为代表题生成完整详细解析。就绪表示当前计划所需解析全部通过校验，页面显示已解析数和目录总题数，未解析题没有占位答案。草稿按稳定题目索引保存，支持非连续选题和断点恢复。失败时点击「继续解析」继续；重新扫描可从头开始。浏览器断开不会取消后台解析，服务重启后须手动恢复。

课堂保存开课时的目录、题目和材料版本快照，重新解析试卷不会改变旧课堂的聊天、板书和对应关系。完成本次计划的目标即可结课，之后增加目标可继续。条分缕析和旧课堂检查原四项证据，其他档位检查具体目标，拔高档要求拓展和变式反馈。讲解记录校验不能替代答案、教材出处或教学质量的人工验收。

点击“我懂了，下一题”会核验本题目标讲解记录；模型漏记时，从本题已保存的导师消息和板书核对原文，不必重讲。点击“就到这里吧，再见”只结束本次交流，保留未完成进度；告别文字和语音结束后，“返回首页”启用。失败或停止时可重试，下一次仍可继续课堂。

试卷、自由提问、外刊和典籍课堂共用试卷课堂样式的输入框，可选图、拍照或粘贴图片，也可只发送图片。Enter 发送，Shift+Enter 换行；每条消息最多 4,000 字和 4 张图片，每张压缩后不超过 2 MiB。外刊提问图片独立于文章来源保存，刷新后仍可查看。

外刊的「解释词语」「分析语法」「说明句意」以真实选区为讲解目标，周围原文只提供语境；自由阅读和文章分析阶段均可使用。快捷回答不会把书签跳到所选段落，也不推进文章分析。回复先核对选区引用与格式，不合格时最多自动重答一次，通过后才保存和播放；这种核对不能保证词义解释正确。本次改动无需数据库迁移。

四种课堂收到完整导师消息后立即并发预取配音，播放时复用同一结果并按消息顺序揭示文字。设置试听与导师试听共用语音请求及取消逻辑。

静音时直接显示文字，不调用 Fish Audio。语音等待超时或失败会回退到文字；明显的语言或长段落问题会尝试修复，语音脚本不合格时不会播放。中日语言验证采用规则检查，音频与中文按消息播放比例同步，尚不支持逐词对齐。

课堂情感标签使用 Fish Audio S2/S2.1 方括号语法：每条可播放语音以一个主要情绪或导师基础语气标签开头，正文为日语。既支持 `[calm]`、`[curious]` 等英文标签，也支持日语自然语言描述；消息修复会参考原标签，缺少句首标签时补导师语气。完整的位置、组合、音效与旧版 S1 区别见 [TTS 情感标签规范](docs/tts-emotion-tags.md)。

## 数据库管理

| 命令 | 用途 |
| --- | --- |
| `npm run db:up` | 启动 PostgreSQL，等待健康检查通过 |
| `npm run db:status` | 查看容器状态及端口 |
| `docker compose --env-file .env.local stop` | 停止本项目数据库容器，保留容器和数据卷 |
| `npm run db:down` | 停止并移除容器，保留数据库数据卷 |
| `npm run db:push` | 将 `src/db/schema.ts` 同步到本地数据库 |

PostgreSQL 16 只监听本机 `127.0.0.1`，默认端口为 `5432`，数据库名为 `app_db`，用户名为 `anilearn`。端口可通过 `.env.local` 中的 `POSTGRES_PORT` 修改。数据保存在 Docker 命名卷 `anilearn_postgres_data` 中，容器重建后仍然保留。

用户名、密码和数据库名在数据卷首次初始化时生效；以后修改环境变量不会自动修改数据库内已有的账户。`db:push` 用于本地开发，已有数据的部署环境应先审查数据库结构变更。
