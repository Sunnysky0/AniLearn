# 典籍翻页阅读验收

典籍使用现有共享阅读器按章分页，位置及书签按不可变版本共享。自动化执行实际组件、保存队列和接口处理器的确定性测试；真实断行、原生划词与手机交互由用户验收。

## 启动前

- 先备份数据库，再审查并应用 `docs/migrations/20261017-book-pagination.sql`，或沿用 `npm run db:push`。此迁移仅增加两张版本所属的表和唯一索引，不重置历史位置、笔记或学习记录。代码实现不自动连接或升级应用数据库。
- 从旧版本升级时保留已有典籍、外刊迁移。健康检查会把新增表计入就绪要求；未升级时不能把 schema 错误视为分页故障。
- 沿用现有启动流程，从 `/books` 进入典籍课堂（地址为 `/book-classroom/...`）。准备内置 Plato，以及包含中文／日文、长段落、图片、表格或公式的已发布典籍。
- 分别使用桌面 `1366×768`、手机 `390×844` 视口。实体手机长按划词另行确认。

## 分页、章节与排版

1. 进入后恢复原文，无自动导师消息或模型／TTS 请求。底部显示本章页码、总页数和阅读位置；长章完成分页前显示「正在分页」。
2. 连续翻页、回翻、输入页码跳转；跨页长段落无缺行或重复。首末页翻页按钮正确禁用，下一页不会直接跳章。
3. 本章末页显示「本章结束」，明确点击「下一章」后进入下一可读章；无正文的结构节点被正常翻章跳过，目录仍可查看它们。最后一个可读章末页显示「全书结束」。
4. 章节目录、本章标题、正文及脚注搜索仍可用。输入聊天、搜索词、书签名称、页码或笔记时，方向键和 PageUp／PageDown 不误翻正文；原生选区与脚注弹窗同样不被打断。
5. 记住中间页某个词句，调整字体、字号、字距、行距、正文宽度，拖动或收起导师栏，改变窗口宽高。相同字符仍在显示页中；刷新后续读锚点不应变成重排后的页首。
6. 检查延迟加载的图片、图像独占页、长表格与公式。图片出现后位置稳定，大内容可局部滚动，不被裁去。
7. 三种主题与手机布局下，目录、续读按钮、页码、章末导航、导师入口及选区工具均可操作，正文仍有可用高度。

## 共享续读与书签

1. 在两章各阅读到中间位置，等待「位置已保存」，再经目录往返，分别恢复各章字符。刷新、退出重进，自动恢复最后阅读的章和位置。
2. 点击「从头阅读」进入首个有正文的主章；点击「本章开头」只回到当前章开头；「回到上次位置」跨章回到本次进入时的固定位置，即使本次已经翻页或加了书签。
3. 在两章添加书签，包括选中文字后添加。检查章名与原文摘录，改名、跨章跳转、删除；调整字号后仍定位到原字符。
4. 同一版本换导师进入另一课堂，位置与书签共用，聊天、读完确认、导读角度状态各自保留。删除一个课堂不影响另一课堂访问共享书签。
5. 离线后在已打开的章节翻页，查看保存失败提示；恢复网络后刷新／重新进入，本地待保存位置能恢复。重试并跨章继续阅读，各章位置和最终续读点均保存；未加载章节不要求离线打开。
6. 两窗口各自阅读，过期写入显示冲突并保留本地位置。明确点击「保存当前位置」后再刷新确认；未确认前不得静默覆盖云端记录。
7. 快速选择不同章节或书签，最终显示最后一次目标。加载失败保留原章和位置，重试后恢复；待保存位置不丢失。
8. 原版本尚无共享记录时，恢复同版本有效历史课堂的位置，新建课堂默认章首不能盖过历史位置。若重新发布目录，新版本与旧课堂的记录相互独立。

## 临时查看、提问与学习状态

1. 定位本章搜索结果、聊天引用或批注，并打开跨章脚注原处；临时查看期间翻页不改续读点。「回到阅读位置」恢复完整字符锚点，明确「从这里继续」才保存并切换当前教学章。
2. 在分页后的词句上原生划选，测试词语、语法、句意、自由提问及批注，引用须对应实际选中文字。检查书内注释弹窗和返回链接，内置 Plato 的跨文件脚注也应可用。
3. 在中间页不选区直接问「解释当前段落」，导师依据当前阅读位置；临时查看时则保留原阅读位置。请求失败后先翻页再重试，重试仍绑定首次发问位置。
4. 阅读、翻章、书签及重排不自动确认读完或开启导读。明确开始本章导读后，原有角度确认、章总结及全书总结解锁规则正常。
5. 切换「我的笔记」「本章导读」后返回原文，字符与书签保留。抽查外刊的翻页、全文搜索、书签和刷新续读，确认共享组件兼容。

## 自动化检查与边界

```text
npm run typecheck
npm run lint
npm run reader:test
npm run reading:test
npm run books:test
npm run math:test
npm run build
```

构建前确认没有其他 Next dev／start／build 进程使用本项目 `.next`。代码交付后执行 `git diff --check` 与 `codegraph sync`。不安排浏览器自动验收、独立 API 审计或真实模型／Fish 请求；自动化通过不代表真实排版、触屏交互或教学质量已经验收。
