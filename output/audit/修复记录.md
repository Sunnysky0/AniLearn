## 已完成

| 问题 | 修复结果 |
| --- | --- |
| 残缺解析仍显示成功 | 先建立题目目录，再逐题校验完整输出与必需字段；只有全部通过才发布。截断、上游报错、错误题号或缺字段均失败，不能开始新课堂。 |
| 解析失败不能继续 | 数据库保存已完成的草稿；重试只处理剩余题目，支持从头重建。服务重启后可手动继续。 |
| 课堂提前结束 | 每题维护解法、知识点、方法、易错点的讲解记录，引用必须出现在本轮实际输出中。覆盖不全不能进入下一题，剩余题目未完成不能结束全卷。 |
| 重新解析破坏旧课堂 | 课堂保存题目快照，旧聊天、进度及板书继续关联原题。重解析失败不覆盖已发布题目。 |
| 并发生成丢失板书 | PostgreSQL 课堂锁保护生成、切题及删除；试卷锁保护解析、页面追加及编辑删除。锁连接与工作连接分开；异常与取消后释放。 |
| 长消息和语言混用 | 长段落按短消息拆分，保留原内容及完整公式。违规输出尝试修复为中文聊天和日语语音；修复失败时保留可用中文，不播放不合格脚本。 |
| 静音仍合成，语音可能卡住 | 静音直接使用文字显示；服务端 12 秒、客户端 15 秒超时，失败回退文字。离开课堂取消请求及播放器。 |
| PDF 静默截断 | 浏览器与服务端统一每份最多 12 页。超限提示实际页数，需要拆分，不丢弃尾页。 |

## 仍需真实材料验收

没有真实模型与 Fish Audio 密钥，本次使用模拟模型和音频，没有验证官方接口、实际声线、发音或高考解题质量。

题目数量取自视觉模型生成的目录，完整性校验无法发现目录本身的 OCR 遗漏。答案、教材出处及讲解覆盖的语义仍由模型判断，未加入教材检索或独立答案核验。语言检查为规则检测，不能保证识别所有混合语言。中文按日语音频播放比例展开，不是逐词对齐。

逐题解析及异常消息修复会增加模型调用次数。解析在当前服务进程运行，已完成内容可恢复，但服务重启后需要点击继续解析，不会自动调度。
