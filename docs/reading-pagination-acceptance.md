# 外刊翻页阅读验收

本次改动将外刊正文切换为自适应单页，典籍保持滚动阅读。自动化采用 Node 测试和可控 DOM 几何数据；CSS 的真实断行、原生选区与手机操作由用户在浏览器验收。

## 启动前

- 备份数据库，审查并应用 `docs/migrations/20261017-reading-pagination.sql`，或使用现有 `npm run db:push`。本次实现不自动连接或升级应用数据库。
- 沿用已有启动流程。准备一篇英文、一篇日文，以及包含超长段落、公式或长文的文章；使用已经确认的原文即可，无须重新 OCR。
- 分别使用桌面 `1366×768` 和手机 `390×844` 视口。物理手机上的长按选区需另行检查。

## 连续阅读与排版

1. 打开阅读课堂：显示原文，不自动生成导师消息或请求配音。长文分页完成后显示总页数。
2. 连续翻到中间页，再返回前页；跨页长段落不缺行、不重复，正文没有整页纵向滚动。超大公式等内容可在局部滚动。
3. 输入页码并按 Enter 跳转；首末页按钮正确禁用，末页显示全文结束，不自动开始分析。
4. 点击正文后使用左右方向键、PageUp／PageDown。编辑搜索词、页码、书签名称、批注或聊天文字时，按键不误翻正文。
5. 记住当前词句，连续调整字号、字体、行距和宽度；开关、拖动导师栏，改变窗口宽高。原词句仍在显示页中，续读锚点不因重排改变。
6. 在三种主题下检查正文、导航和弹窗的对比度；手机上页码、导师入口和选区工具不遮挡彼此。

## 书签与续读

1. 在中间页添加书签，并改名；选中具体词句后也可添加书签。重新打开书签面板，名称与摘录正确。
2. 添加第二个书签，跳转两处并删除其中一个。书签定位跟随字符，不受字号变化影响。
3. 在保存状态变为「位置已保存」后刷新、退出重进，恢复到该字符所在页。
4. 点击「从头阅读」，再点击「回到上次位置」，回到本次进入时的字符。
5. 切换同一文章版本的导师课堂，确认位置和书签共用，聊天、批注、笔记和分析进度各自独立。删除一个课堂后，另一个课堂仍能访问书签。
6. 在浏览器离线状态下翻页，确认显示保存失败；重新进入后本地位置可恢复。恢复网络后重试，刷新确认服务端已保存。
7. 两个窗口打开同一版本，各自翻页：过期窗口应显示冲突，保留其当前位置；主动点击「保存当前位置」后再刷新确认。
8. 如需验证换版，先保留旧课堂，再重新校对并确认文章。新旧版本分别保存位置和书签，旧课堂原文保持不变。

## 选区、批注和分析

1. 在跨页段落的中间页选中英文／日文词句，分别测试解释词语、分析语法、说明句意和自由提问；引用必须对应实际选中文字。
2. 添加、编辑批注，切换「我的笔记」后返回原文，确认批注和阅读位置保留。
3. 搜索其他页的词句，或从聊天引用、批注定位原文；翻页仍处于临时查看。点击「回到阅读位置」恢复原点；点击「从这里继续」才保存查看位置。
4. 阅读到末页后手动开始文章分析，原有阶段、角度确认和完成流程正常。刷新后恢复原有分析状态，翻页不推进它。
5. 打开典籍课堂，抽查原来的滚动、排版恢复、搜索、原生选区及脚注，确认默认阅读方式保持正常。

## 自动化命令

```text
npm run typecheck
npm run lint
npm run reader:test
npm run reading:test
npm run books:test
npm run math:test
npm run build
```

构建与运行中的 Next.js 进程不可同时使用同一 `.next` 输出。本次不运行浏览器自动化或独立 API 审计，也不调用真实模型／Fish 服务进行验收。
