# TTS 情感标签规范

依据用户提供的 Fish Audio《Emotion Control》文档。以下区分 Fish 支持的能力与 AniLearn 的课堂约定；组合数量和情绪选择属于生成规则，程序校验不能判断情绪语义或实际声音效果。

## 模型与请求

| 模型 | 标签语法 | 描述范围 |
| --- | --- | --- |
| S2-Pro / S2.1-Pro（AniLearn 默认 `s2.1-pro`） | `[happy]`、`[優しく穏やかな口調]` | 简短的自然语言描述，不限于固定英文标签 |
| S1（旧版） | `(happy)`、`(sad)(whispering)` | 文档列出的固定标签集 |

标签直接嵌入 Fish 请求的 `text`，没有单独的 `emotion` 字段。请求仍为 `{ text, reference_id, format: "mp3" }`，模型由 `model` 请求头选择。日语正文也可以使用英文控制标签，标签不是需朗读的正文。

AniLearn 当前的生成、修复和试听约定面向 S2/S2.1。现有日语方括号描述是有效的 S2 写法，无需全部改成英文。切换到 S1 不会自动转换标签；不能把任意 S2 自然语言描述只换成圆括号，就认为符合 S1 固定标签集。

## 课堂约定

1. 每条可播放的 `<ja>` / `messages.speech` 以一个主要情绪或导师基础语气标签开头。原文没有句首标签时，程序补 `tutor.voiceStyle`；空白配置使用 `[calm]`。配置只有描述文字时会包装为方括号标签。
2. 一句使用一个主要情绪；短消息通常一个即可。可以叠加表达方式或音效，同句最多组合三个标签，不使用相互矛盾的情绪，也不频繁切换。这比 Fish 的自由组合能力更克制，适用于教学短句。
3. 情绪标签紧贴它所控制句子的开头。基础语气体现导师人设；情境标签可用于提问、肯定、鼓励和安抚，不必每句重复基础语气。
4. 标签必须使用半角 `[`、`]` 并完整闭合；描述简短，不能空白、嵌套或跨行。S2 生成不得使用 S1 的 `(happy)` 写法。
5. 标签只进入 `<ja>`、存储的 `speech` 和 TTS 请求。中文聊天 `<zh>`、板书与笔记保持原内容。语音正文必须为日语；公式转成日语读法，禁止 LaTeX、Markdown 和中文正文。
6. 消息修复必须参考原语音及其中符合语境的标签，分拆后每条仍以主要情绪或语气标签开头。修复结果漏了标签时补导师基础语气；语音不可用时保留中文、将 `speech` 留空，绝不只发送一个标签给 Fish。

## 标签类别与位置

| 类别 | 示例 | 放置规则 |
| --- | --- | --- |
| 情绪 | `[calm]`、`[confident]`、`[curious]`、`[proud]`、`[empathetic]` | 放在所控制句子的开头 |
| 自然语言情绪或风格 | `[encouraging]`、`[slightly happy]`、`[優しく穏やかな口調]` | 描述简短；句子级控制放句首 |
| 表达方式 | `[soft tone]`、`[whispering]`、`[in a hurry tone]` | 放在表达方式开始的位置；课堂通常用正常或柔和语气 |
| 强调 | `[emphasis]` | 放在需强调的词或短语之前 |
| 人声效果 | `[laughing]`、`[chuckling]`、`[sighing]`、`[clear throat]` | 放在声音发生处；按需要搭配自然发声文本，课堂避免无关效果 |
| 停顿 | `[break]`、`[long-break]` | 放在实际停顿处，分别为短停顿与长停顿 |
| 背景效果 | `[audience laughing]`、`[background laughter]`、`[crowd laughing]` | Fish 支持，但 AniLearn 的一对一课堂不生成 |

`[emphasis]`、停顿与音效不是情绪。Fish 允许表达方式和音效出现在文本中间，不能强制把所有标签移动到最前面。导师不得用嘲讽、愤怒、吼叫或尖叫对待学生。

## 示例

```text
[curious] まず、何を求める問題でしょうか。
[proud] よくできました！その考え方で合っています。
[empathetic][soft tone] 焦らなくて大丈夫です。一緒に確認しましょう。
[confident] ここで [emphasis] 両辺から一を引きます。[break] すると、答えが分かります。
[優雅で落ち着いた丁寧な口調] では、条件を一つずつ確認しましょう。
```

## 校验与验证边界

程序检查方括号是否完整、非空且无嵌套，并在忽略控制标签后验证日语正文；原标签仍完整保留在 Fish 的 `text` 中。直接调用 `/api/tts` 可提交无标签的日语，课堂的句首补标签由导师消息准备与保存流程负责。静音、取消、超时与纯文字回退遵守现有播放规则。

S2 支持自由描述，因此不以英文标签白名单判断有效性。规则校验与模拟音频只能确认标签被保留和传递，不能证明 Fish 对某个描述的实际表现。情绪强度、停顿效果及声线匹配需要使用真实 Fish 音频试听。
